FactionOS ("the Bot", "we", "our") is an independent Discord bot designed to provide management, statistics, verification, and organizational tools for factions in the online game TORN.

This Privacy Policy explains what personal information FactionOS collects, how it is processed, stored, protected, and under what circumstances it may be shared or deleted.

By using FactionOS, you acknowledge the data processing described in this policy. Where consent is required, it will be requested separately.
Depending on the features used, FactionOS may process the following information:

Discord Information
- Discord user IDs, usernames, and server IDs
- Server membership and role information
- Bot configuration and administrative settings
- Verification status and related records
- Interactions with Bot commands, buttons, and forms
TORN Information
- TORN player IDs and usernames
- Faction membership and positions
- War participation, attacks, respect, and chain statistics
- Organized crime participation and activity
- Relevant financial records and payout calculations
- Other game statistics required by enabled features
API Credentials

FactionOS may store TORN API keys and registered FFScouter API keys voluntarily submitted by authorized users.

API credentials are used only for the functionality for which they are provided.

Verification and Consent Records

Where applicable, FactionOS records verification consent, withdrawal status, and associated timestamps.
Information is processed to:
- Verify TORN accounts and faction membership
- Synchronize Discord roles and permissions
- Generate war dashboards and faction statistics
- Calculate PPH, PPR, and Hybrid payouts
- Maintain faction banking and accounting records
- Support organized crime tracking
- Provide personalized gym statistics and training recommendations
- Maintain server settings and dashboard updates
- Protect Bot functionality against misuse
- Respond to support and privacy requests
FactionOS does not sell personal information or use it for third-party advertising.
FactionOS uses encrypted storage for supported API credentials.

The current implementation uses Fernet encryption for stored TORN and FFScouter API keys.

Credentials are not intended to be displayed publicly or shared with ordinary Discord members.

Authorized functionality may require decrypting a stored key temporarily to communicate with the relevant API provider.

Users may revoke their API credentials through the relevant provider.

FactionOS does not require TORN account passwords.

No electronic storage or transmission system can guarantee absolute security.
FactionOS may associate Discord accounts with TORN player accounts to verify faction membership and manage Discord roles.

Depending on the available verification method, account linking may use TORN's existing Discord connection or a voluntarily provided API key.

Where explicit consent is required, users may grant or withdraw that consent.

Withdrawing consent may prevent continued use of features that depend on account verification.

Withdrawal does not automatically erase information that must be retained for a valid legal reason.
